# Заявки с сайта → бот @Ereventbot_bot

Сайт лежит на GitHub Pages — это просто набор файлов, без своего сервера.
Чтобы бот отправил сообщение, нужен его секретный ключ (токен). Положить
токен в файлы сайта нельзя: их видит любой посетитель, и бота уведут.

Поэтому между сайтом и Telegram стоит маленький посредник — файл
`telegram-relay.js`. Токен хранится в нём, на стороне сервера. Сайт просто
отправляет туда данные формы, посредник пересылает их в бота.

Разворачивается на Cloudflare Workers: бесплатный тариф, 100 000 заявок
в сутки, карта не нужна.

## Что нужно сделать один раз

1. **Написать боту.** Откройте `@Ereventbot_bot` в Telegram и нажмите
   «Старт». Без этого бот не сможет вам ответить.

   Если заявки должны видеть несколько человек — создайте группу,
   добавьте туда бота и всех, кого нужно.

2. **Завести Worker.** Зарегистрируйтесь на dash.cloudflare.com →
   Workers & Pages → Create → Start with Hello World → Deploy.
   Имя можно любое, например `erevent-leads`.

3. **Вставить код.** Откройте Worker → Edit code, сотрите пример,
   вставьте содержимое `telegram-relay.js`, нажмите Deploy.

4. **Прописать четыре переменные.** Worker → Settings → Variables and
   Secrets → Add:

   | Имя | Тип | Значение |
   |-----|-----|----------|
   | `BOT_TOKEN` | **Secret** | токен бота от `@BotFather` |
   | `CHAT_ID` | Text | куда слать заявки (см. шаг 5) |
   | `ALLOW_ORIGIN` | Text | `https://msnacemusic-gif.github.io` |
   | `SETUP_KEY` | Text | любая строка, нужна только на шаге 5 |

   **Токен вставляйте только сюда** и только типом Secret — тогда его
   не видно даже в панели. Никому не пересылайте: кто знает токен, тот
   управляет ботом и читает все заявки.

   Сохраните и нажмите Deploy ещё раз.

5. **Узнать `CHAT_ID`.** Откройте в браузере
   `https://<адрес-воркера>/chats?key=<ваш SETUP_KEY>` — увидите список
   тех, кто писал боту, с их номерами. Возьмите нужный `id`, впишите его
   в переменную `CHAT_ID` (шаг 4) и снова Deploy.

   Для группы: сначала напишите в неё любое сообщение, потом откройте
   ту же ссылку — там появится группа с отрицательным `id`.

6. **Подключить сайт.** Пришлите адрес воркера (вида
   `https://erevent-leads.<ваш-логин>.workers.dev`) — я впишу его
   в `script.js` в строку `LEAD_ENDPOINT` и выкачу. До этого момента
   форма работает как раньше: показывает «Заявка отправлена», но никуда
   ничего не шлёт.

## Что приходит в бота

```
🔔 Новая заявка с сайта

Имя: Иван Петров
Телефон: +7 (963) 699-72-95
Дата и площадка: 12 сентября, ВДНХ
Ответить в: WhatsApp
Комментарий: Нужен звук и свет

СОБЫТИЯ РУМ — https://msnacemusic-gif.github.io/erevent-landing/
```

Приложенный файл приходит отдельным документом с той же подписью.
Файл больше 20 МБ Telegram не принимает — тогда придёт только текст
с пометкой, что вложение не прошло.

## Защита от спама

В форме есть скрытое поле, которого человек не видит. Роботы заполняют
все поля подряд — такие заявки посредник молча отбрасывает, в бота они
не попадают. Если спам всё-таки пойдёт, скажите: добавлю ограничение
по частоте отправки.

## Проверить, что всё работает

Отправьте заявку с сайта. Если сообщение не пришло, откройте
Worker → Logs в панели Cloudflare — там видно, что ответил Telegram.
