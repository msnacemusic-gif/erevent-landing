# Заявки с сайта → бот @Ereventbot_bot + почта

Сайт лежит на GitHub Pages — это просто набор файлов, без своего сервера.
Чтобы бот отправил сообщение, нужен его секретный ключ. Положить ключ в файлы
сайта нельзя: их видит любой посетитель, и бота уведут.

Поэтому между сайтом и получателями стоит маленький посредник — файл
`telegram-relay.js`. Ключи хранятся в нём, на стороне сервера. Сайт отправляет
туда данные формы, а посредник рассылает заявку:

- **в Telegram** — сообщением в `@Ereventbot_bot`;
- **на почту** — тем же текстом, дублем;
- **вложение** — кладёт в хранилище и добавляет ссылку на скачивание.

Каналы независимы. Если Telegram отказал, а почта ушла — заявка не потеряна,
форма покажет успех. Ошибку посетитель увидит, только если не сработало ничего.

Разворачивается на Cloudflare Workers: бесплатный тариф, 100 000 заявок в сутки.

## Шаг 1. Основа — Telegram (уже настроено)

| Переменная | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | **Secret** | токен бота от `@BotFather` |
| `CHAT_ID` | Text | куда слать заявки |
| `ALLOW_ORIGIN` | Text | `https://msnacemusic-gif.github.io` |
| `SETUP_KEY` | Text | любая строка, нужна только чтобы узнать `CHAT_ID` |

Узнать `CHAT_ID`: откройте `https://<адрес-воркера>/chats?key=<ваш SETUP_KEY>`
и возьмите оттуда нужный `id`. Для группы сначала напишите в неё что угодно.

**После любого изменения переменных нажимайте Deploy заново** — иначе они
не применятся.

## Шаг 2. Дубль на почту

Отправку писем делает Brevo: бесплатно 300 писем в сутки, карта не нужна,
достаточно подтвердить один почтовый ящик.

1. Зарегистрируйтесь на **brevo.com**.
2. **Senders, Domains & Dedicated IPs → Senders → Add a sender.** Впишите
   `info@erevent.ru`, на этот ящик придёт письмо со ссылкой — подтвердите.
3. **SMTP & API → API Keys → Generate a new API key.** Скопируйте ключ,
   он показывается один раз.
4. В Cloudflare добавьте три переменные и нажмите Deploy:

| Переменная | Тип | Значение |
|---|---|---|
| `MAIL_API_KEY` | **Secret** | ключ из Brevo |
| `MAIL_FROM` | Text | `info@erevent.ru` — тот адрес, что подтвердили |
| `MAIL_TO` | Text | куда слать заявки; несколько адресов через запятую |

Поле «Ответить» в письме подставляется автоматически: если посетитель оставил
почту, ответ уйдёт прямо ему — достаточно нажать «Ответить» в почтовой программе.

Пока эти переменные не заданы, посредник просто не шлёт писем, всё остальное
работает как раньше.

## Шаг 3. Хранилище для тяжёлых файлов

Telegram принимает от бота документ до 50 МБ, почта — и того меньше. Файлы
крупнее должны где-то лежать, чтобы в заявку попала ссылка.

1. В Cloudflare: **R2 Object Storage → Create bucket**, имя, например,
   `erevent-leads`. R2 бесплатен до 10 ГБ, но при включении Cloudflare
   попросит привязать карту — списаний в пределах бесплатного объёма нет.
2. Откройте воркер → **Settings → Bindings → Add → R2 bucket**.
   Имя переменной — ровно `FILES`, бакет — созданный.
3. Добавьте переменную `PUBLIC_URL` со значением адреса воркера
   (`https://lingering-credit-51ce.msnace-music.workers.dev`) и нажмите Deploy.
4. Чтобы старые файлы не копились: бакет → **Settings → Object lifecycle
   rules** → удалять объекты старше, например, 90 дней.

Ссылка на файл содержит случайный 32-значный ключ — подобрать его нельзя,
поисковикам страница закрыта. Но ссылка работает у всякого, кто её получил,
так что пересылать её посторонним не стоит.

Когда хранилище включено, предел вложения на сайте можно поднять с 50 до 90 МБ:
в `script.js` строка `var MAX_UPLOAD_MB = 50;`. Скажите — поменяю и выкачу.

## Защита от спама

В форме есть скрытое поле, которого человек не видит. Роботы заполняют все поля
подряд — такие заявки приходят с пометкой «⚠️ Похоже на спам», но **приходят**:
потерять живую заявку хуже, чем получить помеченный спам.

## Если что-то не работает

**Worker → Logs** в панели Cloudflare — там видно, что ответили Telegram и Brevo.

Частые причины: не нажали Deploy после добавления переменных; в `ALLOW_ORIGIN`
лишний хвост (должно быть ровно `https://msnacemusic-gif.github.io`); не нажали
боту «Старт»; в Brevo не подтверждён адрес отправителя.
